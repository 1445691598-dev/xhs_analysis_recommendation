本软件全程使用cursor+Gemini vibe coding 制作，部分小红书数据爬虫代码来源于网络，自行整理优化
本网页功能如下：
  1）可使用py代码自动抓取博主小红书主页，抓取其主页所有笔记ID | 标题 | 点赞 | 封面链接
  2）单独/批量抓取多篇帖子的 ID | 标题 | 正文内容 | 发布时间 | 点赞 | 收藏 | 评论 | 分享 | 笔记链接 | tag标签
  3）以上所有类型抓取结束后自动生成csv.
  4）将数据给deepseek以后，输入建议备注与偏好，可自动生成账号定位，潜在用户画像以及内容建议，热点话题
