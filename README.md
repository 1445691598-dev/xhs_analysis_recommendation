本网页全程使用cursor+Gemini vibe coding 制作，部分小红书数据爬虫代码来源于网络，自行整理优化

具体网址请点击：https://xhsanalysisrecommendation-hsqonpdgzbgz2bx5yzvsvj.streamlit.app/

本网页功能如下：

1）可使用py代码自动抓取博主小红书主页，抓取其主页所有笔记ID | 标题 | 点赞 | 封面链接
  
2）单篇/批量抓取多篇帖子的 ID | 标题 | 正文内容 | 发布时间 | 点赞 | 收藏 | 评论 | 分享 | 笔记链接 | tag标签

3）以上所有类型抓取结束后自动生成csv. 初步生成数据预览，评论词云，评论热力图，高频标签，互动标签与情感分析等

4）将数据自动发送给关联大模型（deepseek），输出账号运营建议，包括但不限于账号定位，潜在用户画像以及内容建议，近期热点话题等
